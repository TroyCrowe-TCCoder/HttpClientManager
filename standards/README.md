# Repository-Local Standards

This folder contains approved overrides and addenda to the global governance baseline for this repository.

- **Global baseline:** [Global Governance Standards](../../GlobalStandards/docs/standards/global-governance-standards.md)

## Usage

Place only repository-specific deviations here. Each override file should:

1. State which global rule it overrides or extends.
2. Provide a rationale approved by the repository owner.
3. Be kept to the minimum scope needed — prefer conforming to global standards wherever possible.

No files in this folder yet — this repository currently conforms fully to the global baseline.
